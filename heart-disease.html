PROJECT 03

Heart Disease Prediction

Machine Learning Approach Using Logistic Regression

Project Overview

Heart Disease Prediction is a machine learning project developed using Python to analyze patient data and predict the likelihood of heart disease.

The project uses patient information from a dataset and applies Logistic Regression as the machine learning algorithm for prediction.

Project Objective

The main objective of this project is to analyze medical attributes in patient data and build a machine learning model capable of predicting the likelihood of heart disease.

Technologies Used

Python Pandas NumPy Scikit-learn Matplotlib Seaborn Logistic Regression

Project Workflow

01

Dataset

Patient information is loaded from a CSV dataset for analysis.

02

Data Analysis

Pandas and NumPy are used to inspect and analyze the patient data.

03

Visualization

Matplotlib and Seaborn are used to visualize patterns and relationships in the dataset.

04

Prediction

Logistic Regression is applied to predict the likelihood of heart disease.

Machine Learning Algorithm

Logistic Regression is used as the primary machine learning algorithm. The model analyzes the available patient attributes and generates a prediction based on the trained data.

Python Libraries

  • Pandas – Data manipulation and analysis.
  • NumPy – Numerical operations and data processing.
  • Matplotlib – Data visualization.
  • Seaborn – Statistical data visualization.
  • Scikit-learn – Machine learning model implementation.
