PROJECT 01

Crowd-X

AI-Based Crowd Congestion Management System

Project Overview

Crowd-X is an AI-based congestion management system designed to monitor crowd density in real-time using computer vision. The system analyzes CCTV camera footage and detects people to estimate crowd density.

When the crowd exceeds a predefined limit, the system can generate alerts to help improve crowd monitoring and safety.

Key Features

  • Real-time crowd detection
  • Person detection using YOLO
  • CCTV/IP camera monitoring
  • Crowd density estimation
  • Automatic congestion alerts
  • Live monitoring dashboard
  • Computer vision based analysis

Technologies Used

Python YOLO OpenCV Flask Computer Vision

How It Works

01

Camera Input

CCTV/IP camera footage is used as the real-time video source.

02

Object Detection

YOLO detects people from the video frames.

03

Density Analysis

The detected people are analyzed to determine crowd density.

04

Alert

An alert is generated when the crowd exceeds the defined threshold.
